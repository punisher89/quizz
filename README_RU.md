# КВИЗ LIVE 2 — тестовая ветка для ПК

**Ветка:** `test/trivial-pursuit-live-2`. **Статус:** игровой прототип, отдельный от прежней стабильной сборки.

Новая сборка независимой викторины, ориентирующаяся на *формат* телевизионной игры Trivial Pursuit Live! 2 (PS4, 2022). **Это не копия игры Ubisoft и не перенос её оригинальных файлов.** Нет фирменных персонажей Ubisoft, оригинальной музыки, озвучки, графики или банка вопросов. Иллюстрации и четыре портрета являются сгенерированным концепт-артом, не скопированным из PS4.

## Что добавлено в тестовой версии

- Новая яркая арена, экраны, 4 стилизованных персонажа и переключение аватара нажатием на его портрет.
- Classic: каждый участник за себя; Versus: локальная игра 2 на 2, команды делят сектора и суммируют результаты.
- Выбор обычных (108) либо авторских семейных (48) вопросов; без доступа к закрытой базе Ubisoft.
- Рандомизация трёх центральных раундов в полном пятираундовом матче.
- Раунды Quickstarter, Switchagories, Close Call, Grab Bag и Rapid Fire, включая 16 плиток/8 верных в Grab Bag; в тестовой версии алгоритмы начисления и тайминги адаптированы и не заявлены точными 1:1.
- До четырёх USB/Bluetooth-геймпадов через браузерный Gamepad API. При одном контроллере возможна передача геймпада по очереди.
- Оригинальные синтезируемые UI-сигналы; оригинальные аудиотреки игры PS4 не используются.

## Запуск

Распакуйте архив и откройте `QuizShow-Live-2-Test.exe` на Windows 10/11 (использует установленный Edge/Chrome). Альтернатива: открыть `index.html` в браузере. Весь контент локальный, интернет для игры не нужен.

## Управление

Крестовина / левый стик — перемещение по ответам, `A` на Xbox / `✕` на PlayStation — выбор, `Start` / `Options` — пауза; на клавиатуре стрелки, Enter, Esc. 1–4 контроллера. **Управление и игровой цикл проверяются отдельно, но запуск на реальном ПК с PS4-контроллерами не подтверждён.**

## Сборка и тесты

`npm test` — проверки игровой логики и структуры вопросов.

Windows launcher: `GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H windowsgui" -o QuizShow-Live-2-Test.exe launcher.go`

Electron (если установлен Node.js): `npm install`, затем `npm start` или `npm run build:win`.

## Следующие шаги

Для приближения к точной PS4-версии нужно покадрово сверить правила, тайминги и UX каждого режима с её легально доступными геймплейными записями и оригинальными ресурсами, на использование которых есть разрешение. Онлайн/Twitch и конкретные аудио/3D-модели Ubisoft отсутствуют.
